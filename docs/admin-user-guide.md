# 同工管理入口使用说明

管理入口：<https://prayer.diagport.com/admin>

## 首次登录

管理员会单独发送管理入口、账号和临时密码。首次登录后，页面会先要求设置自己的新密码；新密码至少 12 个字符。请不要把账号和密码发在微信群里。

## 每日发布

1. 打开“发布内容”，选择“晨修”或“宣教动态与见证”，填写图片对应的日期。
2. 从手机相册选择已经下载的清晰原图。一次可以选择多张；上传后可以用上、下箭头调整顺序，也可以移除图片。
3. 需要稍后检查时选择“保存草稿”；确认内容无误后选择“发布内容”。草稿不会出现在同工试用阅读页面。
4. 标题和说明可以不填，系统会用栏目和日期生成标题。上传完成前请保持页面打开。

每组最多 20 张，合计小于 60 MB，单张不超过 20 MB。请从微信群先下载原图，缩略图或无法看清文字的图片不要上传。

## 修改与归档

在“内容管理”可以按栏目、状态或标题查找内容。点击“编辑内容”可以修改日期、栏目、标题和说明；若选择新图片，会整组替换原来的图片。已发布内容可以归档下架，归档内容也可以恢复为草稿，检查后再发布。

## 宗教动态

已核实的新短讯会在提交后自动出现在主应用和备用阅读站。未核实的仍先出现在「宗教动态」，状态是待审，卡片上带「待核实」。这类条目要逐条点「公开」或「驳回」。

「一键公开已核实」默认不显示。只有管理员打开对应开关后，这个按钮才会出现，并且仍然只公开已核实且仍在待审的条目。按钮上的数字是将要公开的条数；没有这样的条目时，按钮是灰的，不能点。点击后会再问一次，确认框里仍然是这个条数。取消则什么都不公开。

不论一次自动公开或一键公开多少条，内容版本只增加 1，备用阅读站会随后更新一版。未核实、已驳回、已经公开的条目都不会被新的提交改掉。

若公开错了，或后来发现某条已核实动态不实，在同一页对那一条点「撤下」。撤下后它会从公开页面去掉，内容版本增加 1，备用阅读站会再更新一版。同一条再被提交也不会自动回来。需要撤下多条时逐条操作。待审条目上的对应按钮仍是「驳回」。

## 迫害筛选

打开「迫害筛选」。这里只列待审和已公开的动态。标题或摘要里有迫害、监禁、拘留、persecution 等词时，卡片会标成「建议候选」。地区或来源名里的词不算。

已经核实、又标成建议候选的动态，会在提交后直接公开并出现在祷告页，并从「宗教动态」和备用阅读的宗教动态列表里移出。不用再点「设为需要祷告」。还没核实的，即使命中这些词也不会自动过去；确认后点「设为需要祷告」，祷告页上会带「待核实」。待审条目点这个按钮时会同时公开。

误判时点「排除」。排除之后它不再进入祷告页；如果本来已经公开，会回到宗教动态列表。记录还在，没有删除。点「取消排除」后，仍符合上面规则的会再回到祷告页。

分流变化时，内容版本加 1。备用阅读站随后会更新「需要祷告」一页。阅读接口的缓存同时看这个版本和当前列出了哪些条目；版本数字还没变、列表成员已经变时，浏览器和边缘也会重新取列表。

## 管理同工账号

管理员可在“同工账号”创建编辑同工或管理员账号、禁用/启用账号，以及重置临时密码。重置密码后，请把临时密码单独告知同工；对方下次登录会被要求先修改密码。

手机网络较慢时，请等待页面提示完成；如果上传中断，不会自动发布半组图片，重新选择完整图片组后再试即可。
