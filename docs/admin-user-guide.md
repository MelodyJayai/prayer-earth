# 同工管理入口使用说明

管理入口：<https://prayer.diagport.com/admin>

## 首次登录

管理员会单独发送管理入口、账号和临时密码。首次登录后，页面会先要求设置自己的新密码；新密码至少 12 个字符。请不要把账号和密码发在微信群里。

## 每日发布

1. 打开“发布内容”，选择“晨修”或“宣教动态与见证”，填写图片对应的日期。
2. 从手机相册选择已经下载的清晰原图。一次可以选择多张；上传后可以用上、下箭头调整顺序，也可以移除图片。
3. 需要稍后检查时选择“保存草稿”；确认内容无误后选择“发布内容”。草稿不会出现在同工试用阅读页面。
4. 标题和说明可以不填，系统会用栏目和日期生成标题。上传完成前请保持页面打开。

每组最多 20 张，合计小于 60 MB，单张不超过 20 MB。请从微信群先下载原图，缩略图或无法看清文字的图片不要上传。

## 修改与归档

在“内容管理”可以按栏目、状态或标题查找内容。点击“编辑内容”可以修改日期、栏目、标题和说明；若选择新图片，会整组替换原来的图片。已发布内容可以归档下架，归档内容也可以恢复为草稿，检查后再发布。

## 管理同工账号

管理员可在“同工账号”创建编辑同工或管理员账号、禁用/启用账号，以及重置临时密码。重置密码后，请把临时密码单独告知同工；对方下次登录会被要求先修改密码。

手机网络较慢时，请等待页面提示完成；如果上传中断，不会自动发布半组图片，重新选择完整图片组后再试即可。
