# 同工试用说明

本轮手机网页试用地址：**https://prayer.diagport.com**。打开网址即可体验，免下载、免注册。

备用阅读地址：**https://reader.bytelanework.com**。请一并收藏；主站打不开或持续转圈时，可以直接换用此地址，按“晨修”和“宣教动态与见证”阅读。备用站保存完整页面与图片，不依赖主站服务器实时响应，也不需要登录。

若仅是主应用加载较慢，也可使用主站轻量页：**https://prayer.diagport.com/reader/index.html**。

进入后点击底部 **“晨修·宣教”**，可在“晨修”和“宣教动态与见证”栏目之间切换，也可以按月份筛选，或搜索日期查看内容。点击卡片进入详情，长图按原顺序上下滑动阅读。

如果在微信群内打开不正常，请点击右上角菜单，选择“在浏览器中打开”；若仍在转圈，请使用备用阅读地址。本轮主要用于体验内容阅读；发布祷告及相关记录暂只保存在当前设备，不代表已经同步到线上。微信群后续新增内容由授权同工在主站后台上传并发布，系统不会自动读取微信群。备用站通常在发布后 15 分钟左右更新；同步失败期间保留上一完整版本。

如发现内容或显示问题，请反馈：日期、栏目、问题描述、截图，以及所用手机浏览器。
